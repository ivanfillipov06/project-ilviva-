# Виджет банковских операций клиента

Проект реализует логику обработки данных для виджета банковских операций клиента: фильтрацию операций по статусу и сортировку по дате. Разработка ведётся с использованием [GitFlow](https://my.sky.pro/student-cabinet/stream-lesson/259358/theory/9), соблюдением стандартов PEP 8 и проверкой кода линтерами.

## Установка

1. Клонируйте репозиторий на локальную машину:
   ```bash
   git clone <git@github.com:ivanfillipov06/PythonProject.git>

2. Создайте и активируйте виртуальное окружение (при необходимости):

python -m venv venv
#### Для Linux / macOS:
source venv/bin/activate
#### Для Windows:
venv\Scripts\activate
3. Установите зависимости проекта (если используется poetry или pip):

pip install -r requirements.txt
#### или
poetry install
